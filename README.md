# MCDII Mod Manager

A mod manager for Minecraft Dungeons II (Blueprint Loader mods). Install, toggle, rename and delete mods without digging through the game folder.

## Requirements

- [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons2/mods/2) by Ewan Howell, installed separately. Mods don't run without it.
